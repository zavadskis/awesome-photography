# Contribution Guidelines

Thank you for helping improve Awesome Photography. Please make sure your pull request follows these guidelines.

## Adding to this list

- Search previous suggestions before making a new one, to avoid duplicates.
- Add one link per pull request, and make the title descriptive, for example `Add darktable`.
- Make sure the resource is genuinely useful for photographers and that you would recommend it yourself.
- Use this format: `- [Name](https://link) - Short description.`
  - The description starts with a capital letter, ends with a full stop and stays short (one sentence).
  - Do not start the description with "A" or "An", and avoid marketing language.
- Add new entries at the bottom of the relevant section.
- Link to the official page of the project, tool or resource. Use HTTPS where possible.
- Free and open-source tools are preferred. Paid tools are welcome if they are widely used by professionals.
- No affiliate links, referral codes or tracking parameters.
- No NSFW content, pirated material or link farms.
- Check your spelling and grammar, and remove any trailing whitespace.

## Updating your pull request

Sometimes a maintainer will ask you to change something. Please update your branch (amend or add commits) rather than opening a new pull request.

## Broken links

If you find a dead link or a resource that no longer fits, open an issue or a pull request that removes or replaces it.

## Code of conduct

Be kind and respectful. Contributions that are offensive or abusive will be closed.

By contributing, you agree that your contribution is released under the [CC0 1.0](LICENSE) public domain dedication.
